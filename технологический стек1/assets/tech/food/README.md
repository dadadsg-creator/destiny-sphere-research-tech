# Пищевое производство Воранеров

## GREENHOUSE_FARM

- `source/voraner-greenhouse-farm-v01-concept.png` — концепт инженерного парника с производственной пристройкой;
- `source/voraner-greenhouse-farm-v01.prompt.md` — назначение, конструкция и граница с биологической архитектурой Лиенсу;
- `source/voraner-greenhouse-farm-v01-cutout-raw.png` — прозрачный мастер;
- `exports/voraner-greenhouse-farm-v01-color.png` — игровой цветной слой;
- `metadata/voraner-greenhouse-farm-v01.json` — одноклеточный манифест.
- `source/voraner-greenhouse-farm-v02-wide-study.png` — поисковый вариант с хорошо читаемой фермой, но слишком широкой площадкой;
- `source/voraner-greenhouse-farm-v02-concept.png` — компактная фермерская версия с хозяйственным навесом;
- `source/voraner-greenhouse-farm-v02-cutout-raw.png` — прозрачный мастер V02;
- `exports/voraner-greenhouse-farm-v02-color.png` — игровой слой V02;
- `metadata/voraner-greenhouse-farm-v02.json` — текущий одноклеточный манифест;
- `source/voraner-greenhouse-farm-v02.prompt.md` — причины отказа от заводской рампы и художественная граница с Лиенсу.

Будущая анимация: медленное движение вентиляции, конденсат на стекле, чередование спектра ламп и движение пищевых контейнеров в узле выдачи.
