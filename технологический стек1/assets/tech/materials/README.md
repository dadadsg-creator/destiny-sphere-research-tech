# Материальные производства Воранеров

## NANO_CRYSTALLIZER

- `source/voraner-nano-crystallizer-v01-concept.png` — утверждённый реалистичный одноклеточный концепт;
- `source/voraner-nano-crystallizer-v01.prompt.md` — функциональный и художественный контракт;
- `source/voraner-nano-crystallizer-v01-cutout-raw.png` — необрезанный прозрачный мастер;
- `exports/voraner-nano-crystallizer-v01-color.png` — цветной игровой слой без среды и внешней тени;
- `metadata/voraner-nano-crystallizer-v01.json` — одноклеточный игровой манифест.
- `previews/voraner-nano-crystallizer-v01-production-district.png` — контрольная посадка на клетке 11 вместе с жильём, стази-сборщиком и кадериумной кузницей.
- `source/voraner-nano-crystallizer-v02-dispatch-concept.png` — производственная версия с герметичной выдачей готовых нанокристаллов;
- `source/voraner-nano-crystallizer-v02-dispatch-cutout-raw.png` — прозрачный мастер V02;
- `exports/voraner-nano-crystallizer-v02-dispatch-color.png` — игровой слой V02;
- `metadata/voraner-nano-crystallizer-v02-dispatch.json` — одноклеточный манифест V02;
- `source/voraner-nano-crystallizer-v02.prompt.md` — причина изменения и художественный контракт.

Будущая анимация может использовать отдельные слои вращения или роста кристалла, вертикального энергетического потока, коротких импульсов в питающих магистралях и слабой пульсации света внутри герметичной камеры.
