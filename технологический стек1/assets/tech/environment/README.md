# Окружение жилой зоны Воранеров

`source/voraner-residential-environment-atlas-v01.png` — отклонённый первый опыт с самостоятельными платформами. Он сохранён для истории, но runtime его не использует: бордюры и перспектива платформ не совпали с клетками движка.

`source/voraner-residential-ruins-atlas-v02.png` — принятый прозрачный атлас трёх руин без собственной поверхности, созданный встроенной генерацией изображений по двум ориентирам проекта:

- архитектура и материалы — `assets/tech/residential/exports/voraner-residential-v02-color.png`;
- свет — `concept-art/lighting/voraner-single-desert-se35-v01.png`.

Атлас содержит разрушенную арку, упавший стазипилон и вскрытый кольцевой модуль. Каждый объект имеет только компактный нерегулярный слой обломков, занимает одну клетку и использует общую поверхность под собой. Свет приходит справа-снизу под 35°, тени направлены влево-вверх.

`source/voraner-sandy-hive-background-v01.png` — единая почти ровная песчано-каменистая подложка всей соты. Runtime использует её копию из `exports/` размером менее 3,5 МБ как первый визуальный слой. В самой картинке нет дорог, каналов, сетки и границ клеток; точная сетка `48 × 26` остаётся отдельным невидимым интерактивным слоем.

Runtime дополнительно использует три файла руин `*-v02-color.png` из `exports/` общим объёмом менее 0,9 МБ. Атлас руин режется воспроизводимо командой:

```powershell
python tools/slice_environment_atlas.py assets/tech/environment/source/voraner-residential-ruins-atlas-v02.png assets/tech/environment/exports --layout ruins
```

Финальный запрос: прозрачный производственный атлас для изометрической HTML5-стратегии; один горизонтальный ряд из трёх археологических руин без плит, платформ, бордюров и угловых опор; точная ортографическая изометрия 2:1 как у жилого дома; тёплый жёсткий свет справа-снизу под 35°; без песка, растений, персонажей, текста, UI и водяных знаков.

Запрос для поверхности: единая широкая подложка древнего искусственного мира в ортографической изометрии 2:1; почти ровная песчано-каменистая плоскость, спокойный центр под плотную застройку, низкие выходы породы, мелкие камни, трещины и наносы песка; без скал, высоких уступов, зданий, растений, дорог, каналов, сетки и UI; тёплый свет справа-снизу, короткие тени влево-вверх.
