# Окружение жилой зоны Воранеров

`source/voraner-residential-environment-atlas-v01.png` — исходный прозрачный атлас 3 × 2, созданный встроенной генерацией изображений по двум ориентирам проекта:

- архитектура и материалы — `assets/tech/residential/exports/voraner-residential-v02-color.png`;
- свет — `concept-art/lighting/voraner-single-desert-se35-v01.png`.

Верхний ряд содержит три повторяемых типа клетки: целую, выветренную и сервисную. Нижний ряд содержит три индивидуальные руины: арку, упавший стазипилон и вскрытый кольцевой канал. Свет приходит справа-снизу под 35°, тени направлены влево-вверх.

Runtime использует только шесть оптимизированных PNG из `exports/`. Три типовые клетки повторяются без дополнительных файлов; каждая руина загружается один раз. Атлас режется воспроизводимо командой:

```powershell
python tools/slice_environment_atlas.py assets/tech/environment/source/voraner-residential-environment-atlas-v01.png assets/tech/environment/exports
```

Финальный запрос: прозрачный производственный атлас для изометрической HTML5-стратегии; сетка 3 × 2; три совместимые бело-золотые платформы с голубыми стазиэлементами и три археологические руины; ортографическая изометрия 2:1; тёплый жёсткий свет справа-снизу под 35°; без песка, растений, персонажей, текста, UI и водяных знаков.
