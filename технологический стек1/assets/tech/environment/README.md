# Окружение жилой зоны Воранеров

`source/voraner-residential-environment-atlas-v01.png` — отклонённый первый опыт с самостоятельными платформами. Он сохранён для истории, но runtime его не использует: бордюры и перспектива платформ не совпали с клетками движка.

`source/voraner-residential-ruins-atlas-v02.png` — принятый прозрачный атлас трёх руин без собственной поверхности, созданный встроенной генерацией изображений по двум ориентирам проекта:

- архитектура и материалы — `assets/tech/residential/exports/voraner-residential-v02-color.png`;
- свет — `concept-art/lighting/voraner-single-desert-se35-v01.png`.

Атлас содержит разрушенную арку, упавший стазипилон и вскрытый кольцевой канал. Каждый объект имеет только компактный нерегулярный слой обломков, занимает одну клетку и использует общую процедурную поверхность под собой. Свет приходит справа-снизу под 35°, тени направлены влево-вверх.

Runtime использует только три файла `*-v02-color.png` из `exports/` общим объёмом менее 0,9 МБ. Единая песчано-каменистая поверхность строится кодом в точной геометрии клетки; технических каналов и дорог в ней нет. Атлас режется воспроизводимо командой:

```powershell
python tools/slice_environment_atlas.py assets/tech/environment/source/voraner-residential-ruins-atlas-v02.png assets/tech/environment/exports --layout ruins
```

Финальный запрос: прозрачный производственный атлас для изометрической HTML5-стратегии; один горизонтальный ряд из трёх археологических руин без плит, платформ, бордюров и угловых опор; точная ортографическая изометрия 2:1 как у жилого дома; тёплый жёсткий свет справа-снизу под 35°; без песка, растений, персонажей, текста, UI и водяных знаков.
