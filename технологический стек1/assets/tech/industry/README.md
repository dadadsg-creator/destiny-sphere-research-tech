# Промышленные здания Воранеров

## KADERIUM_FORGE

- `source/voraner-kaderium-forge-v01-concept.png` — первый реалистичный концепт; удачен по функции и атмосфере, но основание занимает несколько клеток;
- `source/voraner-kaderium-forge-v02-compact-concept.png` — компактная одноклеточная переработка с сохранёнными печью, подачей руды, встроенным краном и высокой теплоотводящей башней;
- `source/voraner-kaderium-forge-v03-single-cell-concept.png` — первая вертикальная одноклеточная версия, ещё с неуместным парадным входом;
- `source/voraner-kaderium-forge-v03-cutout-raw.png` — сохранённый промежуточный прозрачный экспорт этой отклонённой версии с дверью;
- `source/voraner-kaderium-forge-v03-dispatch-concept.png` — исправленный концепт: готовые слитки выходят через автоматический промышленный шлюз;
- `source/voraner-kaderium-forge-v03-dispatch-cutout-raw.png` — прозрачный мастер исправленного здания;
- `exports/voraner-kaderium-forge-v03-dispatch-color.png` — компактный игровой слой `V03`;
- `metadata/voraner-kaderium-forge-v03-dispatch.json` — одноклеточный манифест `V03`;
- `source/voraner-kaderium-forge-v03.prompt.md` — точный запрос и причина отделения одноклеточной версии от будущего двухклеточного комплекса;
- `source/voraner-kaderium-forge-v02.prompt.md` — требования к утверждаемому направлению.
- `source/voraner-kaderium-forge-v02-cutout-raw.png` — необрезанный прозрачный мастер утверждённого V02;
- `exports/voraner-kaderium-forge-v02-color.png` — обрезанный цветной игровой слой без среды, дыма и внешней тени;
- `metadata/voraner-kaderium-forge-v02.json` — одноклеточный манифест кузницы.
- `previews/voraner-kaderium-forge-v02-residential-district.png` — контрольная посадка на клетке 17 рядом с жилым комплексом и стази-сборщиком.

Печь, стационарный жар и отражённый оранжевый свет пока находятся в цветном слое. Дым, колебание жара, пульсация печи и бегущие огни будут изготовлены позднее отдельными анимированными слоями.
