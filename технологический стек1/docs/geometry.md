# Геометрия пилота

## Источник истины

Геометрия перенесена из `client/src/map/hexGrid.ts` без изменения игровых координат.

| Параметр | Значение |
|---|---:|
| Половина ширины клетки | 24 |
| Половина высоты клетки | 13 |
| Bounding box клетки | 48 × 26 |
| Радиус соты | 9 |
| Число клеток | 217 |
| Anchor здания | `(24, 26)` |

Логические единицы не равны физическим пикселям текстуры. PixiJS масштабирует готовую сцену под экран.

## Вершины клетки

Отсчёт ведётся от левого верхнего угла bounding box:

```text
             V0 (24, 0)
          /               \
 V5 (0, 6.5)             V1 (48, 6.5)
 |                                   |
 V4 (0, 19.5)           V2 (48, 19.5)
          \               /
             V3 (24, 26)
```

## Порты соединения

Порт находится в середине соответствующей грани:

| Направление | Индекс | Координата | Смещение соседней клетки |
|---|---:|---:|---:|
| северо-восток | 0 | `(36, 3.25)` | `(24, -19.5)` |
| восток | 1 | `(48, 13)` | `(48, 0)` |
| юго-восток | 2 | `(36, 22.75)` | `(24, 19.5)` |
| юго-запад | 3 | `(12, 22.75)` | `(-24, 19.5)` |
| запад | 4 | `(0, 13)` | `(-48, 0)` |
| северо-запад | 5 | `(12, 3.25)` | `(-24, -19.5)` |

Переход между двумя зданиями строится по общей грани, а не по центрам клеток.

## Пилотная камера

До первого наложения реального 3D-рендера фиксируются стартовые параметры:

- тип: ортографическая;
- азимут: `45°`;
- высота камеры: `30°`;
- вертикали здания остаются вертикальными на экране;
- основное освещение приходит сверху справа, экранная тень направлена влево вниз;
- камера, экспозиция и направление света одинаковы для всех экспортов.

Значения камеры считаются пилотными. Они блокируются окончательно после совпадения первого здания с шаблоном клетки без ручного растяжения.

## Визуальный envelope

Для жилого модуля Воранеров первого этапа:

- основание: не более `46 × 25` логических единиц;
- допустимый декоративный выход основания: до `2` единиц;
- рекомендуемая ширина верхнего силуэта: `72–88` единиц;
- абсолютный максимум ширины: `96` единиц;
- рекомендуемая высота над anchor: до `104` единиц;
- абсолютный максимум высоты: `112` единиц;
- выход ниже anchor: не более `2` единиц;
- высокие элементы не должны закрывать anchor ближайшего переднего ряда.

Широкий верхний силуэт допускается благодаря сортировке по нижней точке. Функциональное основание всегда принадлежит одной клетке.

## Масштаб текстуры

Мастер-рендер и логический размер разделены. Пример: файл шириной 1024 пикселя может отображаться шириной 82 логические единицы.

```ts
sprite.scale.set(logicalWidth / texture.orig.width);
```

Это устраняет зависимость размера здания от размера экспортированного PNG/WebP.
