# Стандарт математической тени

Дата первой фиксации: 2026-10-02. Текущий временно принятый пресет повторно снят из живого интерфейса 2026-10-05 после добавления склейки силуэта. Машинно-читаемая копия хранится в `docs/shadow-preset-v01.json`.

## Зафиксированные коэффициенты

| Группа | Параметр | Значение | Назначение |
|---|---|---:|---|
| Свет | Экранный азимут | `220°` | Тень уходит влево и вверх по экрану, как в кадре исходной игры. |
| Свет | Высота звезды | `33°` | Определяет базовую длину луча через тангенс угла. |
| Свет | Мировой азимут Blender | `−14.210263°` | Даёт экранный азимут тени `220°` при камере `45° / 30°`. |
| Проекция | Изометрическое сжатие | `0.84` | Компенсирует разницу между экранной высотой здания и расстоянием по земле. |
| Проекция | Длина на 1 px высоты | `1.29 px` | Вычисляется как `0.84 / tan(33°)`. |
| Силуэт | Порог альфы | `26 / 255` | Убирает слабый ореол прозрачных пикселей. |
| Силуэт | Шаг столбцов | `1 px` | Используется каждый столбец исходного PNG. |
| Силуэт | Толщина луча | `2.25 px` | Соединяет соседние проекции в сплошную маску. |
| Силуэт | Склейка силуэта | `0.8 px` | Радиус в итоговых логических пикселях; соединяет лучи и скругляет их окончания. |
| Силуэт | Поправка основания | `+0.060` высоты изображения | Согласует линию контакта PNG с фактическим основанием здания. |
| Смешивание | Математическая тень на земле | `74%` | Основная тень под PNG-зданием. |
| Смешивание | Физическая тень на земле | `74%` | Эталонный слой, экспортированный из Blender. |
| Смешивание | Математическая тень на соседнем фасаде | `42%` | Вычисленная маска поверх цветового слоя соседнего здания. |
| Смешивание | Физическая тень на соседнем фасаде | `42%` | Ослабленный эталонный Blender-слой для сравнения. |
| Смешивание | Размытие | `2 px` | Скрывает ступенчатость расчётного PNG-контура. |

## Формула

Для каждого столбца альфа-маски находятся верхний и нижний непрозрачные пиксели. Экранная высота столбца измеряется от исправленной линии основания до верхнего пикселя. Длина луча равна:

`L = Hscreen × compression / tan(elevation)`

При принятых коэффициентах `L ≈ Hscreen × 1.29`. Конечная точка луча получается умножением длины на единичный экранный вектор азимута `220°`. Лучи всех столбцов объединяются в одну чёрную маску. Склейка `0.8 px` применяется после учёта отношения исходного PNG к логическому размеру объекта, поэтому визуальная плотность не меняется между ассетами разного разрешения.

## Порядок слоёв

1. Поверхности клеток и их детали.
2. Математические и физические тени на земле.
3. Цветовые слои зданий в изометрическом порядке глубины.
4. Математические и физические тени, пересечённые с альфа-масками соседних зданий.
5. Эмиссия, энергетическое свечение и интерфейсные отметки.

Фасадная тень никогда не рисуется на собственном здании источника. Для каждого источника его теневая маска пересекается только с цветовой альфа-маской остальных зданий. Благодаря этому грунтовая часть остаётся под архитектурой, а попавшая на соседний объект часть появляется поверх его цвета и под свечением.

## Рабочий стенд

Режим калибровки: `package=shadowLab&scenario=shadowLab`. Две исходные пары показывают физическую и математическую тень на соседнем здании; остальные клетки доступны для ручной застройки. Все коэффициенты доступны в панели «Модификаторы тени». Изменение геометрического параметра очищает кеш масок и немедленно пересобирает математические тени.

Рабочее применение: `package=voranerMix&scenario=district`. Тот же алгоритм автоматически строит наземную и фасадную тень для всех одиночных домов и объединённых комплексов на 19-клеточном квартале.

Физическая проверка: `voraner-l1-blockout-light220-e33-v02.blend`. В Cycles основной блик синего купола находится правее центра и немного ниже его середины; правая нижняя золотая окантовка освещена сильнее. Падающая тень остаётся связанной с основанием и имеет экранный азимут `220°`.
