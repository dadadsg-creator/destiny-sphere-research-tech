# Пропорции жилого здания Воранеров

Дата измерения: 2026-10-11.

## Метод

Сравнивается отношение видимой ширины нижней части силуэта к полной архитектурной высоте от линии посадки до верхней точки. Для прозрачных PNG нижняя ширина вычисляется воспроизводимо как максимальный непрерывный горизонтальный span в нижних `35%` альфа-силуэта при пороге alpha `64`. Масштаб растрирования не влияет на отношение.

Оригинал взят из `client/public/assets/buildings/tech/RESIDENTIAL_BUILDING.png`. Это растрирование символа `RESIDENTIAL_BUILDING` из `old-sphere/ds/flash/build_tech.lib.swf`; исходный Flash-символ остаётся векторным источником, PNG используется только для измерения его границ.

У концептов с непрозрачным окружением граница измерена по видимому основанию вручную, поэтому результат указан с допуском около `±0,03`.

## Результат

| Вариант | Основание / высота | Отличие от оригинала | Вывод |
|---|---:|---:|---|
| Оригинальный Flash-вектор | `1,23` | — | Контрольная пропорция |
| Новый функциональный лист, жилой дом | `≈1,20` | `−2%` | Практически совпадает по массе |
| Одиночный дом в пустыне | `≈1,20–1,23` | `0…−2%` | Практически совпадает |
| Прототип v03, низкий купол | `1,26` | `+2%` | Очень близко |
| Прототип v05, низкий овальный | `1,18` | `−4%` | Близко |
| Прототип v02, дом с высокой башней | `0,86` | `−30%` | Заметно выше и уже оригинального ритма |

Для контроля обычный bounding-box оригинального альфа-силуэта равен `47 × 35 px`, то есть `1,34 : 1`. Эта величина больше основной архитектурной пропорции из-за деревьев и боковых деталей. Поэтому для сравнения зданий полезнее нижний контур `43 px / 35 px = 1,23`.

## Вывод для следующего арта

- массовые одноклеточные здания стоит удерживать в диапазоне основания к высоте примерно `1,15–1,30`;
- диапазон `1,20–1,25` хорошо связывает новый концепт с ритмом оригинальной игры;
- значения ниже `1,0` оставляются для редких вертикальных акцентов, науки, связи и специальных башен;
- высокая башня v02 не ошибочна сама по себе, но не должна задавать пропорцию большинства жилых клеток;
- дальнейшие функциональные листы следует проверять тем же скриптом до подготовки игровых слоёв.

Воспроизводимое измерение прозрачных ассетов выполняет `tools/measure_building_proportions.py`.

## Производственные здания первого функционального листа

Для непрозрачного концепт-листа границы измерены вручную по архитектурному силуэту, без песка и падающей тени; погрешность около `±0,05`.

| Назначение | Оригинальный Flash-вектор | Новый концепт | Изменение |
|---|---:|---:|---:|
| `KADERIUM_FORGE` | `0,56` | `≈1,30` | основание более чем вдвое шире относительно высоты |
| `NANO_CRYSTALLIZER` | `0,72` | `≈1,35` | новый объект почти вдвое шире |
| `PRODIUM_COLLECTOR` | `1,18` | `≈1,15` | практически совпадает |
| `ENERGY_COLLECTOR` | `1,00` | `≈1,05` | практически совпадает |
| `RESEARCH_CENTER` | `0,80` | `≈1,07` | новый научный центр примерно на треть шире |

Старые кузница и нанокристаллизатор были узкими вертикальными машинами. Новый лист трактует их как полноценные цеха, заполняющие клетку оборудованием. Это улучшает функциональную читаемость и посадку на поверхность, но ослабляет связь с вертикальным ритмом оригинальной соты.

Для следующего прохода стоит сохранить широкое рабочее основание, но вернуть одному элементу каждого промышленного здания выраженную вертикальную технологическую доминанту. Целевой компромисс:

- обычный ресурсный сборщик: `1,05–1,25`;
- тяжёлый производственный цех: `0,85–1,10`;
- редкая высокая машина или научный акцент: `0,65–0,90`;
- широкие значения выше `1,25` оставлять для специальных радиальных установок и многоклеточных комплексов.

Неотрисованные пока военные производства подтверждают вертикальный характер старой библиотеки: `LIGHT_WEAPON_MANUFACTURE` имеет `0,67`, `HEAVY_WEAPON_MANUFACTURE` — `0,60`, тогда как более низкая `CONSTRUCTION_FACTORY` имеет `1,10`.
