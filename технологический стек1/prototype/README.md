# Прототип

Изолированный технический стенд модульного жилого комплекса Воранеров. Первый этап работает без npm-зависимостей и проверяет геометрию до подключения PixiJS.

## Почему отдельно

Прототип не должен менять рабочий `client`, пока не проверены:

- геометрия ассетов;
- алгоритм соседства;
- сортировка по глубине;
- игровые состояния;
- производительность;
- художественная читаемость.

## Запуск

```powershell
python -m http.server 4174 --directory ..
```

Открыть `http://127.0.0.1:4174/prototype/`.

Все автоматические проверки:

```powershell
node tests/all.mjs
```

В панели диагностики можно включить автоматический выбор трёх вариантов либо оставить один вариант. Все пакеты используют один загрузчик и один код рендера; различаются только JSON-манифестами и файлами слоёв.

## Текущий результат

Стенд показывает сценарии из `docs/pilot-scenarios.md`, реальные маски соседей, устойчивые идентификаторы групп, переходы, внешний периметр, дворы и центральный акцент. Каждая клетка выбирается независимо по своему гексагону. В автоматическом режиме силуэт, высота и декоративные элементы воспроизводимо зависят от мира, соты, группы и клетки. Художественный пресет Воранеров заменяет точные конфигурации из трёх и семи клеток едиными групповыми ассетами.

Калиброванная математическая тень использует экранный азимут `220°`, высоту звезды `33°` и альфа-силуэт каждого ассета. На 19-клеточном квартале она строится для одиночных домов и объединённых комплексов, сначала на земле, затем отдельным проходом поверх цветовых слоёв соседних фасадов и под эмиссией. Полный стандарт записан в `docs/shadow-calibration.md`.

В художественном режиме поверхность рисуется единым полем без постоянной сетки. Геометрия 19 гексагонов сохраняется для hit test: клетка проявляет контур при наведении, а выбранная клетка получает отдельную жёлтую подсветку.

Сценарий `districtWide` расширяет поверхность до 61 клетки. Центральные 19 клеток сохраняют тот же квартал и строительную логику, а два внешних кольца служат стендом окружения и не заполняются дополнительными жилыми домами. На древней платформе поверх скрытой сетки рисуется единая художественная схема: крупные панели, золотистые стыки, стазиэнергетические каналы, технические люки, сервисные панели, сады, археологическая разметка и узел кольцевых ворот.

После приёмки алгоритмические модули переносятся в `client/src/map/visual-v2`, а тестовые данные остаются здесь.
