Атлас артефактов

Все иконки артефактов (типов) и формы цветных рамок (scope), подготовленные для перерисовки. Картинка артефакта в оригинале — 3 слоя: art_clear (фон слота, не используется в ремастере) → SCOPE_MOV (форма рамки по scope, красится сплошным цветом по prefix/размеру через CSS mask-image) → TYPE_MOV (сама иконка по postfix) поверх. Источники: ASSET_CHECKLIST.md, live-код client/src/data/resourceIcons.ts, декомпиляция artefact.lib.swf/ ArtColors.swf (FFDec, тот же метод, что и для атласов построек/юнитов), сверка полноты — 5 страниц destinysphere.ru (art_zd/art_s/art_k/ art_a/war).

Формы рамок по scope (13)

Белые/серые маски без цвета — цвет в оригинале накатывается программно (Color.setRGB()) по таблице редкости ниже, отдельного перекрашенного PNG на каждую пару scope×редкость в игре никогда не существовало. При перерисовке форму достаточно нарисовать один раз как чистый контур/силуэт — красить будет ремастер-клиент.

Таблица редкости (arr_size) — извлечена декомпиляцией artefact.lib.swf (frame_1/DoAction.as:createArtefact), перенесена в resourceIcons.ts:ARTEFACT_SIZE_COLOR. 16 записей — часть повторяется (одно и то же значение под старым и новым именем уровня редкости, например MAJOR/MIGHTY оба → оранжевый), SILVER/NORMAL — null, то есть форма остаётся некрашеной. Это не отдельные изображения для перерисовки, только референс цвета.
13 карточек убраны из списка иконок-типов ниже как дубликаты этих же форм. В artefact.lib.swf нашлись символы с именами, буквально совпадающими с именами scope (ALLIANCE, BUILDING, COMB, COMBCOMPLEX, IMMEDIATE, LOVE, MEGA, QUEST, RACE, RELIGION, RING, SPHERE, WAR) — сверка геометрии подтвердила: это та же графика, что и формы рамок выше (10 из 13 совпали побайтово, у оставшихся 3 совпал размер и число сегментов кривой, различие — на уровне округления координат). Похоже, artefact.lib.swf тоже хранит копии общих символов рамок — отдельно перерисовывать их не нужно, форма уже здесь.

Иконки-типы (100)

Каждая иконка — то, что игра называет TYPE_MOV/postfix. Один и тот же постфикс переиспользуется во всех scope, где встречается тип (см. тег с перечнем scope на карточке) — отдельной картинки на каждую пару scope×type в игре нет.

REDACTED_CREDENTIALS.txt): ds_artefacttype.typename ⟷ ds_localizedtextlanguage.text (116 строк) и ds_artefactscope.scopename ⟷ … (11 строк). Это авторитетный источник — заменил собой дословный перевод с вики везде, где расходился (нашлось 2 ошибки в переводе: RELIABILITY оказался «прочности», не «надёжности» — то слово принадлежит SECURITY; и CORE_SYNTHESIS/NUCLEAR_FISSION были попарно перепутаны между группами Продиум/Энергия). Все 35 экономических и все 35 «одиночных» военных типов (без CALMNESS, см. ниже) теперь подтверждены живой БД, не предположением.

Убрано из атласа по решению владельца (2026-09-22) — не перерисовываем: DGR, SPY, JOYSTIK1 (не игровые artefact-типы либо неиспользуемый/мёртвый, см. историю), BOXIM, MOUSEICON, PHONEICON, NEWYEAR1, NEWYEAR2 (существуют в ds_artefacttype, но без русской локализации — назначение/актуальность не подтверждены). 8 иконок, было 108, стало 100.

Открытые вопросы (явно помечены на карточках):
  • IGROMIR_ATTACK/IGROMIR_DAMAGE/IGROMIR_DEFEND/ IGROMIR_HITPOINTS — сам символ без _SALE в ds_artefacttype не найден, только IGROMIR_WAR_*_SALE (RU-имя оттуда показано с пометкой «предположение» — вероятно тот же промо-набор с Игромира, что и в COMB-скоупе, но 1:1 связь символ↔тип не подтверждена).
  • ANTIDOT (1 machine-тип) — у владельца есть минимум 2 конкретных quest-инстанса с разными именами («Антидот Куриной слепоты» / «Антидот Холеры»), оба используют эту иконку — не установлено, чему в БД (ds_artefact.artefactname) соответствует каждое.
  • CALMNESS — единственный тип с двумя scope сразу (HOLIDAY2 и WAR, оба подтверждены ASSET_CHECKLIST.md); RU-имя «осмотрительности» подтверждено БД. На карточке отнесён к HOLIDAY2, но реально используется в обоих scope.
  • UNIQUE — обнаружен в ds_artefacttype запросом (RU: «Уникальный»), но не входит в 121 извлечённый графический символ artefact.lib.swf — похоже, у этого типа нет своей иконки вообще. Не включён в атлас (нечего перерисовывать).
«Страшный артефакт Куриной слепоты» / «Ужасный артефакт Холеры» — владелец подтвердил скриншотом админки (Scope: Праздничные, Bonus: ALL), что это тоже HOLIDAY/HOLIDAY2-артефакты, но иконки для них среди 121 извлечённых символов нет — решено не гнаться за ними и не перерисовывать, как и остальные 8 выше.
