# Локальная версия Destiny Sphere

## Неприкосновенность репозитория Максима

- Репозиторий `https://github.com/milmax111/Destiny-Sphere.git` используется только как источник для чтения и получения обновлений.
- Категорически запрещено отправлять в него коммиты, ветки, теги, pull request, releases или любые другие изменения.
- `fetch` из репозитория Максима разрешён. Любое получение обновлений сначала проверяется и затем вручную переносится в нашу локальную версию.
- Вся новая разработка ведётся только в локальной копии `D:\ProjektDS` и в локальных ветках.
- Локальные изменения клиента считаются нашей версией. Они не должны изменять историю или состояние репозитория Максима.
- Публикация нашей версии возможна только после явного указания отдельного репозитория, который не принадлежит Максиму.

## Защита Git

- У `origin` сохраняется адрес чтения репозитория Максима, чтобы при необходимости выполнять `git fetch`.
- Адрес отправки `origin` должен оставаться заблокированным локальной настройкой Git.
- Перед любой отправкой нужно проверить `git remote -v` и убедиться, что целью не является `milmax111/Destiny-Sphere`.
