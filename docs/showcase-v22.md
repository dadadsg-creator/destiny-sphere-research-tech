# Полигон для Максима — V22

Публичный адрес: https://dadadsg-creator.github.io/destiny-sphere-research-tech/

По просьбе пользователя от 2026-10-27 все три жилых варианта (башенный, купольный и овальный) разрешены на траве и земле. Фермы остаются доступными на траве; остальные ограничения матрицы грунтов сохранены. Это правило нашего локального и публичного полигона, не изменение сервера игры.

Подложка по умолчанию в сборке GitHub Pages — `ring-v22`: цельный нативный PNG 3504×2336, 22107460 байт, без уменьшения и без тайлов от старой карты. Это художественная детализация опубликованной ранее V14. Стартовая геометрия сетки и принятые назначения 217 клеток V14 сохранены. Проектный баланс FAQ не подменяет принятую раскладку.

`client/src/map/showcaseV22.ts` содержит снимок локальной сцены от 2026-10-27: 23 работающих здания и параметры света, анимации и объединения. Ворота рисуются отдельно в системной клетке. У всех посетителей одинаковая стартовая сцена; сохранённые в их браузере локальные здания её не заменяют. Падающие тени и анимация включены; контактная тень выключена, как в принятом локальном просмотре.

Строительство, снос, включение/отключение зданий, объединение, сетка, ручная сверка и инженерные настройки доступны. В демонстрационном режиме застройка не сохраняется: обновление страницы возвращает снимок. «Игровая застройка» также возвращает снимок V22. Режим полной застройки доступен через кнопку и `density=full`. Сверка грунтов сохраняется отдельно в браузере, как и раньше.

Ключ OpenAI API, локальный API-сервер, журналы расходов, Blender-проекты и промежуточные эксперименты для этого обновления не требуются. Публикация выполняется только в `dadadsg-creator/destiny-sphere-research-tech`; отправка в репозиторий Максима запрещена.

Проверки: `npm run check:terrain-v22` проверяет коды грунта, изоляцию сверки, счётчик проверенных клеток и совместимость 23 зданий с назначениями. CI собирает сайт с `VITE_SHOWCASE_SCREEN=hive-217` и `VITE_BASE_PATH=/destiny-sphere-research-tech/`.
