# Destiny Sphere / «Сфера Судьбы»

Российская браузерная MMO-стратегия на Adobe Flash, запущенная 23 сентября
2003 года (издатель — DestinySphere GmbH). Игра до сих пор жива: живые
сайты обновляются новостями по состоянию на 2026 год.

- **destinysphere.ru** — версия Classic
- **ds-game.ru** — версия Unlimited
- **billing.destinysphere.ru** — единый биллинг для Classic / Unlimited / Pulsar

Подробнее об игре и её истории — [docs/history-and-background.md](docs/history-and-background.md).

## Структура репозитория

```
old-sphere/   — легаси-исходники игры (заморожены как есть, документируются)
docs/         — документация текущего состояния кодовой базы (см. docs/README.md)
```

Всё содержимое игры перенесено в `old-sphere/`, чтобы освободить корень
репозитория под будущий **ремастер проекта**.

## Документация

Полная документация архитектуры, игрового движка, админ-панели, биллинга и
т.д. — в **[docs/README.md](docs/README.md)**. Это первый проход
документирования (снимок текущего состояния перед ремастером), сделан на
основе чтения исходников `old-sphere/` и живых сайтов.

## Безопасность

Из кодовой базы вычищены все обнаруженные реальные пароли БД и API-ключи
(заменены на плейсхолдеры вида `REDACTED_DB_PASSWORD`).
Репозиторий приватный — так и должно оставаться, пока в `old-sphere/`
присутствуют незашифрованные ссылки на реальную продакшн-инфраструктуру
(хосты, имена БД и т.п., даже без паролей).
