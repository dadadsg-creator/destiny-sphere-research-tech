# V09 — стандартное однорядное кольцо

V09 выделяет из полного замощения V08 один непрерывный ряд одинаковых комплексов. Это принятая конструкция обычного игрового мира.

## Геометрия

- один комплекс: `1` центральная, `6` домашних и `6` нейтральных сот;
- шаг повторения центров в аксиальных координатах: `A = (3, -1)`;
- девять показанных комплексов содержат `117` разных сот;
- вся полоса связна по полным граням, наложений нет;
- первый и последний комплекс соединяются при периодическом замыкании полосы в кольцо.

Для удобства чтения вся решётка повёрнута на `-10,893°`, чтобы вектор повторения шёл горизонтально по экрану. Поворот применяется ко всей решётке целиком, поэтому гексы остаются одинаковыми правильными шестиугольниками.

## Слои мира

Нейтральные пустыни образуют два края игровой полосы. За ними находятся неигровые несущие плечи, две встречные туннельные реки и прозрачная защитная оболочка. Эти слои не занимают игровые соты и не меняют их геометрию.

Техническая маска выделяет границы соседних комплексов золотым. Внешний контур девяти модулей является границей фрагмента, а не разрывом настоящего кольца.
