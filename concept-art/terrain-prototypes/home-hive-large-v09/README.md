# Домашняя сота V09 — безопасная игровая область

V09 исправляет принципиальную геометрическую ошибку прошлых вариантов: сетка
из 217 клеток больше не совпадает с линией несущей рамы. Поле целиком
масштабировано вокруг центра коэффициентом `0.72`, сохраняя исходную топологию,
индексы и взаимное сопряжение клеток.

Проверяемый контракт:

- все шесть вершин каждой из 217 клеток находятся внутри конструктивного гексагона;
- полный прямоугольник каждого из 10 одноклеточных типов здания помещается на каждой клетке и не пересекает раму;
- трёх- и семиклеточные комплексы перед отрисовкой проверяются целиком;
- если крупный комплекс не помещается у края, занятые клетки остаются отдельными зданиями;
- свободная полоса между игровым полем и рамой является древним техническим фартуком и не содержит активных клеток.
