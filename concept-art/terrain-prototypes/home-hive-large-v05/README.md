# Большая домашняя сота V05

## Назначение

Подложка игрового экрана на 217 клеток с уточнённой геометрией комплекса. Центральный в кадре шестиугольник — домашняя сота игрока.

## Соседи домашней соты

- за нижней горизонтальной гранью находится общая центральная сота комплекса;
- за нижними диагональными гранями находятся две соседние домашние соты;
- за верхней и двумя верхними диагональными гранями находятся три пустынные нейтральные соты;
- все границы принадлежат одной непрерывной шестиугольной сетке;
- водоёмы внутри сот раздельные и не образуют рек между сотами.

Такая раскладка соответствует фрагменту комплекса: одна центральная сота, кольцо из шести домашних сот и наружное кольцо нейтральных пустынных сот.
