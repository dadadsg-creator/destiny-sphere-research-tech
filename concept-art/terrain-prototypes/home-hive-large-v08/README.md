# Домашняя сота V08 — привязка к игровым поверхностям

`home-hive-large-v08-source.png` — первая художественная подложка, построенная по точной калибровочной маске 217 позиций.

Контракт маски:

- `S`: 92 позиции земли;
- `D`: 35 позиций пустыни;
- `G`: 45 позиций травы;
- `W`: 44 позиции воды;
- `X`: системная позиция `num=108`.

`home-hive-large-v08-terrain-mask.png` — машинная маска в пиксельной проекции подложки `1536 × 1024`. Она нужна только для проверки и следующих художественных проходов; в игровом виде клеточные границы скрыты.

`home-hive-large-v08-terrain-mask-labeled.png` — та же маска с легендой.

`*-overlay.png` — диагностические наложения маски на художественные варианты.

V08 сохраняет точную шестигранную границу V07 и соседние соты. Внутри центральной соты песок собран сверху, трава — в средней полосе, вода — в центре и ниже, земля — по краям и строительным проходам. Границы художественных биомов остаются мягкими, поэтому маска является контрактом назначения клеток, а не требованием рисовать 217 видимых тайлов.
