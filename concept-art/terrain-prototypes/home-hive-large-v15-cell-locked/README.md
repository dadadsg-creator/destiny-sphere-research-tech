# Домашняя сота V15 — поверхность, закреплённая за 217 клетками

V15 решает расхождение художественной подложки и серверного кода грунта. Источник истины — строка `HOME_ART_GROUND` из `client/src/map/locationGround.ts`: `92 S / 35 D / 45 G / 44 W / 1 X`.

## Итоговые файлы

- `home-hive-large-v15-cell-locked-final-art.png` — чистый художественный исходник `1536×1024`;
- `validation-final-art/home-hive-v15-terrain-overlay.png` — контрольное наложение всех 217 индексов и кодов;
- `material-plates/` — четыре цельные пластины материалов: настоящий песок, природный невспаханный грунт, низкий луг и вода;
- `home-hive-large-v15-cell-locked-final.png` — строгая программная сборка до художественного сглаживания;
- `home-hive-large-v15-cell-locked-candidate-02.png` и `candidate-03.png` — сохранённые поисковые варианты;
- `home-hive-large-v15-cell-locked-source.png` — первая отклонённая попытка, повторившая старую форму озера.

Runtime-мастер `4608×3072` лежит в `client/public/assets/hive-lab/home-hive-large-v15-cell-locked-4608.png` и выбирается параметром `ground=ring-v15`.

## Воспроизводимая сборка

1. `tools/render_home_terrain_perspective_mask.ps1` проецирует 217 клеток на фактические шесть граней подложки и создаёт размеченную маску.
2. Рисующая модель создаёт цельные согласованные пластины каждого материала. Она не определяет расположение грунтов.
3. `tools/compose_home_terrain_cell_locked.ps1` объединяет соседние клетки одного кода, вырезает материалы по точным маскам и создаёт строгий промежуточный мастер.
4. Финальный художественный проход сглаживает только узкую полосу перехода, сохраняя топологию областей. Результат повторно проверяется размеченной маской.

Финальный запрос к рисующей модели: сохранить все области строгой программной сборки на прежних местах; убрать видимую гексагональную ступенчатость только в полосе `3–5%` ширины клетки; не создавать новые острова и не соединять области; использовать спокойный настоящий песок, серо-бежевый минеральный грунт, приглушённый низкий луг и глубокую сине-зелёную воду; уменьшить визуальный масштаб камней, растений и рельефа под поле из 217 зданий; удалить сетку, подписи и интерфейс.

Все предыдущие версии сохранены без изменений.
