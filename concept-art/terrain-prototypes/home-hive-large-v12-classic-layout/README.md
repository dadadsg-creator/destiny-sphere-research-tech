# Home Hive large V12 — classic terrain layout

## Художественная раскладка

- центр: единое озеро с островом;
- за озером: широкий связный зелёный луг;
- дальняя верхняя часть: пустыня;
- ближняя часть активной домашней соты: земля;
- центральная сота показана только фрагментом у нижнего края;
- растительность уменьшена до масштаба кустарника при высокой игровой камере.

Подложка не содержит зданий. Все игровые объекты, тени, анимация и состояния
рисуются клиентом отдельными слоями.

## Файлы

- `home-hive-large-v12-classic-layout-source.png` — исходный кандидат;
- `client/public/assets/hive-lab/home-hive-large-v12-classic-layout.png` — точная
  runtime-копия;
- URL-параметр стенда: `ground=ring-v12`.

## Следующая обязательная правка

Художественная береговая линия должна быть совмещена с точной 217-позиционной
маской `HOME_ART_GROUND`, особенно с 44 водными позициями. Сейчас V12 фиксирует
нужный общий образ и масштаб деталей, но не является окончательной картой
разрешённых оснований. Проверка доступна через `terrain-map=on`.

После утверждения раскладки потребуется настоящий крупный мастер. Увеличение
этого файла не считается добавлением детализации.
