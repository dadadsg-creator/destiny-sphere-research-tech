# Home Hive relief and scale study V04

## Задача

Проверить два решения в одном кадре:

1. цельный обычный рельеф без сборки поверхности из заметных плиток;
2. фактический масштаб воранерских зданий относительно полной игровой соты.

## Композиция

- активная домашняя сота занимает около 80–85 % кадра;
- центральная сота показана только верхним фрагментом на переднем плане;
- внешняя геометрия остаётся правильным шестигранником;
- искусственное происхождение поверхности передают граница и редкие древние
  конструкционные детали, а не повторяющаяся плитка;
- в домашнюю соту временно поставлены жилые здания, стази-сборщик, кузница
  кадериума и военная база.

## Предварительная оценка масштаба

Одиночные жилые здания выглядят примерно на `20–25 %` крупнее целевого размера
для визуального поля на 217 позиций. Высокие функциональные здания хорошо
работают как доминанты, но их основания должны оставаться собранными в пределах
назначенного числа клеток.

## Статус

Масштабный художественный этюд `1536×1024`. Это не чистая подложка и не runtime-
ресурс. После утверждения рельефа будет сделан отдельный мастер без зданий; сами
здания останутся независимыми игровыми слоями.
