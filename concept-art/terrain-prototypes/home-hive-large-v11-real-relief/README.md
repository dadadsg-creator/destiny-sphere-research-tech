# Home Hive large V11 — real relief

## Назначение

Чистая квазиреалистичная подложка для проверки совместного масштаба поверхности
и независимых игровых зданий. В активной домашней соте нет запечённых построек.
Нижний край показывает только фрагмент общей центральной соты.

## Runtime

- источник: `home-hive-large-v11-real-relief-source.png` (`1536×1024`);
- клиент: `client/public/assets/hive-lab/home-hive-large-v11-real-relief.png`;
- параметр стенда: `ground=ring-v11`;
- режим нормальной застройки: без `density=full`;
- нагрузочный режим 217 занятых позиций: `density=full&fusions=off`.

## Что проверяется

- здания рисуются отдельными слоями и занимают точные позиции сетки;
- обзор показывает структуру всей территории;
- рабочее приближение показывает примерно несколько десятков клеток;
- полный набор 217 зданий используется только как нагрузочный и предельный
  визуальный тест.

## Ограничения кандидата

Исходник пока имеет концептуальное разрешение. Растительность и мелкий рельеф
слишком контрастны в местах строительства; следующий мастер должен сохранить
правдоподобную поверхность, но дать больше спокойных площадок под основания.
После утверждения композиции потребуется настоящий крупный мастер, а не обычное
масштабирование этого PNG.
